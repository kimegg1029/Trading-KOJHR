# OZU TRADING

OZU TRADING의 GitHub Pages 업로드용 프런트엔드 프로토타입입니다.

## GitHub에 올리는 방법

1. GitHub에서 새 저장소(repository)를 만듭니다.
2. 이 패키지 안의 `index.html`, `README.md`, `.nojekyll`을 저장소 최상위(root)에 업로드합니다.
3. 저장소의 **Settings → Pages**로 이동합니다.
4. **Deploy from a branch**를 선택하고 `main` 브랜치의 `/ (root)`를 선택한 뒤 저장합니다.
5. 배포가 완료되면 GitHub Pages가 표시하는 주소로 접속합니다.

## 현재 포함된 기능

- 오주 / 혜령 사용자 선택 화면(시연용 로그인)
- 피라미드 매수 계산기
- 계정별 투자금 및 공통 가격 범위
- 10회 / 5회 / 3회 분할 설정
- 분할별 예상 가격·투자금·수량 표시
- 시뮬레이션 주문 확인 및 주문 내역
- 계산 결과 CSV 저장
- 계정별 잔고/매도 화면 시안

## 계산 및 주문 기록 동작

예를 들어 오주 4,000,000원, 혜령 2,000,000원, 910만원~810만원, 10회 분할로 설정하면 공통 가격 구간을 기준으로 각 계정의 투자금을 별도로 배분합니다. 시뮬레이션에서 두 계정을 모두 선택한 경우 주문 내역은 오주 10건 + 혜령 10건으로 총 20건이 생성됩니다.

## 중요한 제한사항

- 이 저장소는 **프런트엔드 시뮬레이션**입니다. 실제 업비트/OKX 주문을 전송하지 않습니다.
- 로그인과 Face ID는 시연용이며 실제 인증이 아닙니다.
- 잔고와 시세는 예시 데이터입니다.
- 주문 내역은 브라우저 새로고침 시 유지되지 않습니다.
- 실제 거래소 연결을 위해서는 별도의 안전한 백엔드가 필요합니다. API 비밀키를 HTML이나 GitHub 저장소에 올리지 마세요.
